Introduction

This lab focuses on fundamental programming concepts in the C programming language. It provides practical experience with basic C syntax, programming constructs, and problem-solving techniques.

 Objectives

1. To understand the basic structure and syntax of C programs.
2. To practice using variables and different data types in C.
3. To learn input and output operations.
4. To develop basic problem-solving skills using C.
5. To write, compile, and execute simple C programs.

 C Topics Covered in Lab 03

- Variables and constants
- Data types
- Input and output
- `printf()` and `scanf()`
- Arithmetic operators
- Relational operators
- Logical operators
- Conditional statements
